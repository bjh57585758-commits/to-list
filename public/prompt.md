[역할]
너는 숙련된 프론트엔드 웹 개발자야. 사용자가 매일 자기관리를 실천하고 기록할 수 있는 깔끔한 '월간 달력 기반 Habit Tracker(체크리스트) 웹앱'을 제작해줘.

[핵심 기능 및 UI/UX 요구사항]
1. 월간 달력 레이아웃:
   - 화면 중앙에 7x5 또는 7x6 형태의 월간 달력(Calendar)을 배치해줘.
   - 상단에는 현재 연도와 월(예: 2026년 10월)이 표시되고, [이전달] [다음달] 이동 버튼이 있어야 해.

2. Daily 체크리스트 (5개 항목):
   - 고정 체크리스트 5가지:
     1) 07:00 기상하기
     2) 물 1.5L 마시기
     3) 30분 운동하기
     4) 독서 20분 하기
     5) 취침 전 일기 쓰기

3. 인터페이스 & 동작 방식:
   - 달력의 특정 '날짜(숫자)'를 클릭하면 해당 날짜의 5가지 체크리스트가 담긴 모달(Modal) 팝업창이 나타나야 해.
   - 체크박스를 클릭하면 즉시 완료 상태가 반영되어야 해.
   - 달력의 날짜 셀 내부에는 그날 5개 항목 중 몇 개를 완료했는지 직관적으로 볼 수 있는 데이터 시각화(예: 점 5개 중 완료된 개수만큼 색상이 바뀌는 뱃지 또는 진행률 프로그래스 바)가 표시되어야 해.

4. 데이터 저장 방식:
   - 별도의 백엔드 서버 없이 브라우저의 localStorage를 활용해서 데이터(날짜별 5개 항목 완료 여부 [true/false])를 영구 저장해줘. 페이지를 새로고침하거나 나중에 다시 접속해도 내 체크 기록이 유지되어야 해.

5. 디자인 스타일:
   - 모바일과 PC 화면 모두에서 보기 좋은 반응형 웹(Responsive Web) 디자인.
   - 모던하고 깔끔한 파스텔/모노톤 컬러 톤 (Pretendard 등 정돈된 폰트 적용).

[제출 형태]
- 외부 라이브러리 설치 없이 브라우저에서 바로 실행 가능한 단일 HTML 파일(`index.html`) 형태(HTML, CSS, JavaScript 포함)로 전체 코드를 작성해줘.
